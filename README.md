# ✨ Barbie Princess Charm School Portal ✨
### *Where Magic Meets Modern Web Development*

Welcome to the official digital portal for the **Barbie Princess Charm School**. This is a fully functional, multi-departmental school management system built with **Django** and **Tailwind CSS**.

---

## 🏰 Project Overview
This project was developed as a comprehensive web application featuring three distinct academic departments: **College**, **High School**, and **Elementary**. Each department has its own dedicated space for information and student enrollment.

### Key Features:
* **Triple-App Architecture:** Separate Django apps for College, High School, and Elementary divisions.
* **Database-Driven Enrollment:** Real-time student registration with data persistence using SQLite.
* **Integrity Protection:** Built-in validation to prevent duplicate enrollments using unique email constraints.
* **Barbie-Core UI:** A custom-designed "Pastel Pink & White" theme using Tailwind CSS and HSL variables.
* **Responsive Design:** Fully mobile-friendly layout with a sidebar for news and announcements.
* **Dark Mode:** A "Night Princess" mode featuring deep greys and vibrant pink accents.

---

## 🛠️ Tech Stack
* **Backend:** Python 3.12 + Django 5.x
* **Frontend:** Tailwind CSS (via Play CDN), HTML5, JavaScript
* **Database:** SQLite3
* **Environment:** GitHub Codespaces
